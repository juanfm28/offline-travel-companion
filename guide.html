Installation and recovery

Using local files offline

Install, then import

  1. Open the app's final HTTPS address while connected.
  2. Use the browser's installation menu or Share → Add to Home Screen, where supported.
  3. Launch the installed app and choose Import itinerary. Select a complete, self-contained HTML file you trust.
  4. In Documents, select a folder name and use Import PDFs. Multiple selection is supported where the file picker allows it.
  5. Optional folder import preserves the selected tree and skips non-PDF files. ZIP files are not supported.

Install before importing. Browser tabs and installed apps may have separate storage. Keep the original HTML and PDFs in an independent, downloaded device folder. Cloud-only copies are not an offline backup.

Check offline operation

  1. In Offline status, wait for every shell asset to be cached, request storage protection and choose Check saved files.
  2. Disable network access, including Wi-Fi. Force-close the app and reopen it using its installed icon.
  3. Check the itinerary's images, section links, map controls and daily navigation.
  4. Open several PDFs, including a multi-page document. Test scrolling, zoom and both device orientations.
  5. Restart the device while offline and repeat. Recheck after several days without connectivity where practical.
  6. Confirm that the independent originals also open in the device's file manager without a connection.

A successful file check or service-worker registration does not prove offline launch works. Essential device checks must pass before relying on the app. External web links require connectivity.

Open and replace documents

Tap a PDF filename for its preview. If pages are missing, try Open full screen and use Back to return. A separate browser window may not share the installed app's local files. If viewing fails, use the independent original in your file manager.

Use Replace itinerary to update the HTML without changing PDFs. Use a PDF row's Replace button for one document, or reimport into the same folder with the same filename. Different filenames remain separate files. Recognized DDMM and YYYY-MM-DD filename prefixes sort by month and day within folders.

Replacing imported files needs no deployment and works offline from downloaded originals. Failed validation or storage transactions preserve the previously saved files. Repeat file and offline checks after changes.

Updates and recovery

While connected, choose Check for app update. Finish any import before choosing Update app. Shell updates preserve imported files; repeat the offline checks afterward.

If an imported file is missing, restore it from your independent copy. If the app itself no longer opens offline, reconnect to restore the shell first.

Persistence is not guaranteed. Clearing website data, reinstalling, device storage pressure or changing the app's address can make local files unavailable. A complete storage wipe can remove both the shell and its data, so the app cannot always warn before files disappear. Keep independent originals and avoid clearing data or reinstalling as an update method.
